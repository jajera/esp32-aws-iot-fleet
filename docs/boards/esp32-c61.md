# esp32-c61 — ESP32-C61-DevKitC-1

Primary documented fleet board.

| Field | Value |
|-------|--------|
| **Make / product** | Espressif ESP32-C61-DevKitC-1 |
| **Chip** | ESP32-C61 |
| **USB** | Native USB-Serial/JTAG → `/dev/ttyACM0` (`303a:`) |
| **Status UI** | Serial / future RGB (no OLED) |
| **BOOT** | GPIO **9** (active-low) → `button` event |
| **PIO env** | `esp32-c61` (default) |
| **Thing** | `esp32-c61-01` |
| **Thing Type** | `esp32-c61` |
| **MQTT topics** | `fleet/esp32-c61-01/…` |

## Telemetry

Every 15s to `fleet/esp32-c61-01/telemetry` (includes `chip_temp_c` via IDF temp sensor):

`device_id`, `ts`, `type`, `rssi`, `uptime_s`, `heap_free`, `chip_temp_c`, `chip_model`, `cpu_mhz`, `flash_bytes`, `wifi_ssid`, `wifi_status`, `wifi_channel`, `wifi_ip`, `wifi_gateway`, `wifi_dns`, `model`, `clock_offset_ms`.

BOOT publishes `fleet/esp32-c61-01/events` (`type=button`, `event=press`).

## Onboard

```bash
export AWS_PROFILE=sandbox AWS_REGION=ap-southeast-2 FLEET_ALLOW_AWS=1
THING_NAME=esp32-c61-01 THING_TYPE=esp32-c61 \
  BOARD_ATTR=ESP32-C61-DevKitC-1 PATTERN=esp32-c61 \
  PIO_ENV=esp32-c61 UPLOAD_HINT=/dev/ttyACM0 \
  ./aws/provision-device.sh

# secrets.ini: Wi-Fi + endpoint
pio run -e esp32-c61 -t upload    # /dev/ttyACM0
```

Confirm port:

```bash
ls -l /dev/ttyACM* /dev/ttyUSB* 2>/dev/null
lsusb | rg -i 'espressif|303a|1a86|ch340'
```

CH340 `/dev/ttyUSB*` is Ideaspark / classic ESP32 — use `ideaspark-oled`, not this env.
